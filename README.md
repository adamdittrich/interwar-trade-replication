# Old Partners, New Hierarchies
## Trade Reallocation in Interwar Europe, 1927–1937

**Adam Dittrich — Prague University of Economics and Business**

This repository is the dedicated companion repository for the article's replication materials. It is separate from the author's academic website.

**Publication status:** repository initialization is in progress. Do not treat this initial commit as a complete replication release. A verified release will be identified here when its data, code, documentation, and manuscript files have been published.

The study distinguishes continuity in trading partners from stability in their relative importance. It compares conditional predictions from the pre-crisis bilateral allocation with geographic benchmarks and annually updated trade maps, using separate League of Nations export and import declarations.

The archival repository is openICPSR study 247132: https://www.icpsr.umich.edu/sites/icpsr/view/studies/247132/versions/V2. The existing study record should not be assumed to contain the revised analysis until the corresponding updated release is deposited.

Editorial correspondence and referee reports are not part of the public replication materials.
